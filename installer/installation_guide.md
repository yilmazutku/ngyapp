# Installation Guide

This guide provides instructions for installing the application on Windows 10/11.

## System Requirements

- Windows 10 or Windows 11
- 4 GB RAM (8 GB recommended)
- 500 MB available disk space
- Internet connection for initial setup and updates

## Installation Steps

1. **Download the Installer**
   - Download the installer file (`IlkApp_Setup_1.0.0.exe`) from the provided location.

2. **Run the Installer**
   - Double-click on the downloaded installer file.
   - If you see a security warning, click "Run" or "Yes" to proceed.

3. **Installation Wizard**
   - The installation wizard will guide you through the installation process.
   - Click "Next" to continue.

4. **License Agreement**
   - Read the license agreement.
   - Select "I accept the agreement" and click "Next" to proceed.

5. **Choose Installation Location**
   - Select the folder where you want to install the application.
   - The default location is recommended for most users.
   - Click "Next" to continue.

6. **Create Shortcuts**
   - Choose whether to create desktop and Start menu shortcuts.
   - Click "Next" to continue.

7. **Installation**
   - Click "Install" to begin the installation process.
   - Wait for the installation to complete.

8. **Complete Installation**
   - Click "Finish" to complete the installation.
   - If you selected the option, the application will start automatically.

## First Launch

When you first launch the application:

1. You may be asked to log in with your account credentials.
2. If you don't have an account, you can create one.
3. The application may check for updates.

## Uninstallation

To uninstall the application:

1. Go to Windows Settings > Apps > Apps & features.
2. Find "IlkApp" in the list and click on it.
3. Click "Uninstall" and follow the prompts.

Alternatively:
1. Go to Control Panel > Programs > Programs and Features.
2. Find "IlkApp" in the list and click on it.
3. Click "Uninstall" and follow the prompts.

## Troubleshooting

If you encounter any issues during installation:

- **Error Messages**: Make a note of any error messages and contact support.
- **Installation Fails**: Try running the installer as administrator (right-click > Run as administrator).
- **Application Won't Start**: Make sure your system meets the minimum requirements.
